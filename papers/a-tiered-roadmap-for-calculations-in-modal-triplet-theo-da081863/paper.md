# Version 3 Revision Note

Supersedes
*A Tiered Roadmap for Calculations in Modal Triplet Theory*, version 2.

Reason
The former roadmap mixed obsolete benchmark calculations with open source theorems and repeatedly reopened already certified matrix, Yukawa, electroweak, and threshold work. It also preceded the native gauge-group, finite-triple, one-Higgs, and finite-spectrum results.

Resolution
Version 3 locks the 12/12 embedded-renormalized-SM baseline, retires the few-TeV/CY backfit chain, and replaces repeated status targets by nine named strict-upgrade objects and acceptance tests. It incorporates the new exact finite-geometry results without promoting their still-open numerical source maps.

Retained result
The current one-shared-physical-primitive/profile closure and its reproducible packets remain the operational baseline.

Remaining boundary
Continuum q79 source geometry, a selected upper action, strict observable values, nonperturbative QFT, and unique-branch selection remain stronger upgrades and must not be confused with reopening the closed baseline.

# How to read this roadmap

The word *closed* is always local to a named row and standard. For example, a finite spectrum may be derived exactly while the physical coefficient multiplying it remains profile data. Likewise, an embedding can reproduce every renormalized Standard Model observable in a common scheme without deriving the measured source coordinates. These are different mathematical achievements, and neither should be advertised as the other.

The tiers below are therefore cumulative but not interchangeable. A higher tier may use a lower-tier theorem, but a numerical match cannot retroactively turn a calibration into a source theorem. The result matrix states both the positive result and the scope guard needed to use it correctly.

# Closure vocabulary

Every result must carry one of the following labels:

Structural theorem.
Derived from selected mathematical source data.

Conditional theorem.
Derived only after all displayed assumptions are imposed.

Calibration.
Parameters are chosen using the compared data.

Profile/replay.
Measured coordinates are transported or embedded in a declared scheme.

Diagnostic.
A consistency check whose target entered selection or fit.

Held-out prediction.
The target is absent from source selection, calibration, branch choice, and uncertainty construction.

No result may move between these classes merely because its numerical residual is small.

# Revised tier architecture

## Tier 0: conventions and provenance

Tier 0 fixes units, hypercharge normalization, renormalization scheme, scale, branch identifiers, source ownership, covariance, and code versions. It produces no physical prediction. This tier is mandatory for every numerical claim.

## Tier 1: exact finite and topological structure

Tier 1 contains exact results only with their branch hypotheses. Current examples include the selected $`q=79`$ modulo-448 branch, finite-gerbe/charge data, the 27-by-27 qutrit–Weyl architecture, finite Cech tables, cocycle identities, and the selected retarded orientation representative. The native rank-one, rank-two, and rank-three bundle automorphisms give $`U(1)`$, $`SU(2)`$, and $`SU(3)`$ with faithful quotient $`(SU(3)\times SU(2)\times U(1))/\mathbb Z_6`$. On the selected three-family carrier, the chiral representation and all local and global gauge-anomaly checks close exactly. These results do not prove uniqueness over all MTT branches or automatically determine measured scalar magnitudes.

## Tier 2: geometry-light conditional relations

Tier 2 now separates exact algebra from assumptions. Modal democracy implies $`\sin^2\theta_W=3/8`$ but is not selected by the current profile. Holonomy phase sums require a connection-preserving trivialization. Equal wave speeds require a common principal symbol. Curvature–mass and PPN statements require explicit mass ansatz, positivity, response norms, and physical normalization. Internal spectral gaps are not external cutoffs.

## Tier 3: profile-standard superset execution

The legacy crossing-scale backfit is retired. Current Tier 3 is the audited superset embedding:

- final profile-standard audit: 12/12;

- one shared physical primitive $`P_{\mathrm{EW}}`$ and zero Higgs-specific parameters at the embedding layer;

- selected multi-loop transport and covariance;

## Tier 4: selected geometry and operator execution

The old fitted Calabi–Yau corner is not validated and is retired as numerical authority. The selected rank-two literal Cech–HYM execution is closed 2/2, including finite patching and the continuum tail/Wiener certificate. The internal $`K_{\mathrm{threshold}}`$ response closes 10/10. Charged flavor and Higgs close at the profile standard; CKM also closes at the selected prediction-with-uncertainty criterion. Rank-three transfer, strict scalar value emission, absolute neutrino completion, and strong CP remain stronger targets.

The newer generative finite-geometry lane supplies a sharper structural result. It constructs the 48-state family-diagonal chiral carrier, the particle–antiparticle 96-dimensional finite module, its profile-valued finite Dirac operator, and the minimal neutral algebra summand required by orientability and Poincare duality. The completed triple has a single anomaly-free shared hypercharge circle. Exhaustive finite one-form execution produces three raw scalar doublets, while the selected q79/proto-spinor alignment projector isolates one exact Higgs doublet. The sector-resolved finite gauge/ghost spectra are sourced 10/10 with no continuous parameter.

This last spectrum result also proves an important limitation: after rank/adjoint normalization the selected finite rows are universal. They cannot by themselves emit the observed relative gauge couplings. The two relative gauge coordinates and the physical scale therefore remain profile inputs until a selected continuum HYM/action response supplies them.

# Next computational milestones

1.  **Physical q79 endpoints.** Construct the visible and hidden holomorphic bundles in one Hull–Strominger/HYM chamber, beginning with the explicit $`\eta_9`$ meridian, period, and flat Deligne rows.

2.  **Continuum naturality and execution.** Intertwine the local $`1+2+3`$ carrier with the physical q79 HYM complex, then evaluate the selected rank-102 Hessian blocks, kernel projection, and radii inequalities.

3.  **Upper action.** Define one selected upper differential/action whose automorphisms, zero modes, transferred products, and finite operators reproduce the accepted lower structures.

4.  **Strict observable sources.** Derive the electroweak primitive, relative gauge metrics, nine charged magnitudes, Higgs value, and physical threshold rows from that same source, or retain each explicitly as profile data.

5.  **Neutral and strong-CP completion.** Supply dimensionful neutral blocks and absolute normalization; separately construct the selected flux/threshold axion-current anomaly map and test EDM constraints.

6.  **Quantization and QFT.** Extend the restricted recorder theorem to all allowed contexts and construct a geometry-selected nonperturbative gauge–BRST completion with positivity and continuum control.

7.  **Branch and zero-primitive synthesis.** Upgrade the retarded orientation representative to a global action/measure theorem, and attempt U1 only after its dependency rows close.

# Reproducibility contract

Every milestone must ship raw inputs, immutable source identifiers, units, scheme/scale/loop order, branch choices, parameter ledger, covariance, executable code, deterministic outputs, unit tests, and an acceptance certificate. Held-out claims additionally require a data-separation certificate. Historical packets remain provenance and cannot override their audited successors.

# Conclusion

The program has advanced substantially beyond the original roadmap, but not in the manner that document claimed. The strongest current achievement is a reproducible, shared-operator embedding of the renormalized Standard Model at a clearly declared profile standard, together with a native faithful gauge group, anomaly-free chiral carrier, completed finite triple, one-Higgs projector, exact 10/10 finite gauge spectra, and the HYM and CKM strict upgrades. None of these converts the measured profile coordinates into derived constants. The old Tier-3 and Calabi–Yau numerical chain is retired.

Progress toward a deeper theory is now sharply measurable: close U5, U6, U7–U9 and finally U1 with source theorems rather than fitted replacements. This roadmap is intentionally non-looping: a row changes status only when its named missing object passes its stated acceptance test.
