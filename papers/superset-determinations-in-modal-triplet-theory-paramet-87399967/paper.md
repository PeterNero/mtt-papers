# Purpose of the superset program

MTT can organize several effective encodings through shared carrier, projector, bundle, overlap, and response data. The superset strategy is useful when it asks which observables are jointly representable and which parameters are identifiable from a declared input set. It is not, by itself, a method for deriving measured constants.

We use five disjoint status classes:

1.  **Structural theorem:** follows from selected mathematical data without observed value selection.

2.  **Calibration:** parameters are chosen to reproduce declared data.

3.  **Profile/replay:** measured coordinates are transported through a specified scheme or embedded action.

4.  **Diagnostic:** a comparison tests consistency but was involved in selection or fitting.

5.  **Held-out prediction:** the compared observable was absent from source selection, calibration, branch choice, and uncertainty construction.

Every future execution must publish raw inputs, units, scheme and scale, selection rules, fitted parameters, covariance, branch choices, code, and unit tests.
