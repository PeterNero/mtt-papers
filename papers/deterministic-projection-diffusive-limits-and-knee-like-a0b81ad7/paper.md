abstract: |
  A finite-dimensional deterministic system can produce a stochastic effective law when only a non-injective observable is retained and hidden initial conditions are sampled from an invariant ensemble. We give an explicit invertible example. Its fast subsystem is the hyperbolic toral automorphism generated by $`A=\left(\begin{smallmatrix}2&1\\1&1\end{smallmatrix}\right)`$, its slow coordinate is an affine contraction driven by the centered observable $`\phi(y)=\sin(2\pi y_1)`$, and the observed map forgets the torus coordinate. Standard deterministic homogenization then gives an affine Ornstein–Uhlenbeck limit with exact asymptotic variance $`\sigma^2=1/2`$. At any fixed readout time, the limiting probability of a positive outcome is an exact Gaussian sigmoid. We compute its midpoint, maximal slope, and every quantile width, and prove uniform convergence of the finite deterministic readout curves on compact protocol intervals. The construction is an existence theorem for deterministic microscopic realizations of diffusive threshold laws. It does not derive intrinsic randomness, a first-passage law, quantum collapse, the Born rule, or an MTT-selected physical protocol.

# Version 2 Revision Note

Supersedes
*Deterministic Projection, Diffusive Limits, and Knee–Like Threshold Transitions*, version 1.

Reason
The previous model used the doubling map while calling the full dynamics invertible, reversed the drift geometry at the proposed exit boundary, changed from a stability-crossing model to a different affine-readout model, and then identified an endpoint probability with a first-passage probability. Its comparison with fixed Markov generators was also stronger than the construction justified.

Resolution
This version uses one smooth invertible hyperbolic toral map throughout, declares the invariant initial-condition ensemble that supplies probability, computes the diffusion coefficient exactly, and treats one fixed-time threshold observable consistently from the finite deterministic model to its Ornstein–Uhlenbeck limit. Endpoint and first-passage events are separated, and the Markov comparison is stated as a microscopic realization result rather than a no-go theorem.

Retained result
A smooth invertible finite-dimensional skew product can have a non-injective readout whose ensemble law converges to a diffusion and whose protocol-dependent threshold curve has a finite, exactly computable width.

Remaining boundary
The toy parameters and protocol are not selected by MTT geometry; no physical measurement interaction, Born weights, first-passage theorem, or empirical threshold is derived here.

# Question, picture, and scope

Suppose a complete state is $`(x,y)`$, but an observer records only $`x`$. Even when the update of $`(x,y)`$ is deterministic and invertible, the next value of $`x`$ is not determined by the current value of $`x`$ alone: different hidden values $`y`$ lie in the same observational fiber. If an ensemble of hidden initial conditions is specified, the observed coordinate therefore has a probability law.

This elementary point must be stated carefully. Projection does not make an individual trajectory random. It makes the retained coordinate *statistically incomplete* relative to an ensemble on the discarded coordinates. A diffusion can then appear in a scale-separation limit when the hidden deterministic motion is sufficiently chaotic. Deterministic homogenization makes that statement rigorous .

The purpose of this paper is to put the mechanism in one small model where four facts can be checked separately:

1.  the full finite-step map is a smooth diffeomorphism;

2.  the observational map is non-injective;

3.  the projected ensemble law has a rigorous diffusion limit; and

4.  the limiting fixed-time threshold curve, including its width, is explicit.

The model is not proposed as a quantum measurement theory. In particular, a positive-coordinate readout is only a binary toy observable. It is useful because it isolates what projection plus deterministic homogenization can prove without importing claims about collapse, first passage, or physical probabilities.

# An invertible deterministic source model

## Fast carrier and observable

Let
``` math
\mathbb{T}^2=\mathbb{R}^2/\mathbb{Z}^2,\qquad
A=
\begin{pmatrix}
2&1\\
1&1
\end{pmatrix},
```
and let
``` math
T(y)=Ay\pmod{\mathbb{Z}^2}.
```
Since $`\det A=1`$, $`T`$ is an invertible smooth map of $`\mathbb{T}^2`$. Its eigenvalues are $`(3\pm\sqrt5)/2`$, so neither lies on the unit circle. Thus $`T`$ is a hyperbolic toral automorphism. It preserves normalized Lebesgue measure $`\mu`$, is mixing, and satisfies an invariance principle for sufficiently regular centered observables .

Choose
``` math
\phi(y)=\sin(2\pi y_1).
```
This observable is smooth and centered:
``` math
\int_{\mathbb{T}^2}\phi\,\mathrm{d}\mu=0.
```

## Slow coordinate and protocol

Fix constants
``` math
\gamma>0,\qquad \alpha>0,\qquad s_0\in\mathbb{R},
```
and choose $`0<\varepsilon<\gamma^{-1}`$. Set
``` math
r_\varepsilon=1-\varepsilon\gamma\in(0,1).
```
For a protocol coordinate $`s\in\mathbb{R}`$, define
``` math
\begin{equation}
F_{\varepsilon,s}(x,y)
=
\left(
r_\varepsilon x+\varepsilon\alpha(s-s_0)
+\sqrt{\varepsilon}\,\phi(y),
\;T(y)
\right)
\label{eq:source-map}
\end{equation}
```
on $`\mathcal{M}=\mathbb{R}\times\mathbb{T}^2`$. The retained observable is
``` math
P:\mathcal{M}\longrightarrow\mathbb{R},
\qquad
P(x,y)=x.
```
It is non-injective because every fiber $`P^{-1}(x)`$ contains a full copy of $`\mathbb{T}^2`$.

<div id="prop:diffeomorphism" class="proposition">

**Proposition 1** (The source map is a diffeomorphism). *For every admissible $`\varepsilon`$ and every $`s`$, the map $`F_{\varepsilon,s}`$ in <a href="#eq:source-map" data-reference-type="eqref" data-reference="eq:source-map">[eq:source-map]</a> is a smooth diffeomorphism of $`\mathbb{R}\times\mathbb{T}^2`$.*

</div>

<div class="proof">

*Proof.* Write $`(x',y')=F_{\varepsilon,s}(x,y)`$. Since $`T`$ is invertible and $`r_\varepsilon\ne0`$,
``` math
y=T^{-1}(y'),\qquad
x=
\frac{x'-\varepsilon\alpha(s-s_0)
-\sqrt{\varepsilon}\,\phi(T^{-1}y')}
{r_\varepsilon}.
```
This is a smooth inverse. ◻

</div>

## Where probability enters

Fix $`x_0\in\mathbb{R}`$ and sample only the hidden initial condition,
``` math
y_0\sim\mu.
```
Every sampled pair $`(x_0,y_0)`$ then follows a deterministic orbit. The symbol $`\mathbb{P}`$ below means the pushforward of $`\mu`$ through this deterministic evolution; it is not an additional random forcing at finite $`\varepsilon`$.

Let $`(x_n,y_n)=F_{\varepsilon,s}^n(x_0,y_0)`$. Direct iteration gives
``` math
\begin{align}
x_n
={}&r_\varepsilon^n x_0
+\frac{\alpha(s-s_0)}{\gamma}\left(1-r_\varepsilon^n\right)
\nonumber\\
&+\sqrt{\varepsilon}
\sum_{j=0}^{n-1}r_\varepsilon^{\,n-1-j}\phi(T^j y_0).
\label{eq:finite-solution}
\end{align}
```
The first line is deterministic. The second is a weighted deterministic Birkhoff sum whose ensemble law is induced by $`y_0\sim\mu`$.

# Diffusive limit with an exact coefficient

## The fast variance

The Green–Kubo variance of $`\phi`$ is
``` math
\begin{equation}
\sigma^2
=
\int_{\mathbb{T}^2}\phi^2\,\mathrm{d}\mu
+2\sum_{k=1}^{\infty}
\int_{\mathbb{T}^2}\phi(y)\phi(T^k y)\,\mathrm{d}\mu(y).
\label{eq:green-kubo}
\end{equation}
```

<div id="lem:variance" class="lemma">

**Lemma 2** (Exact asymptotic variance). *For the chosen $`T`$ and $`\phi`$,
``` math
\sigma^2=\frac12.
```*

</div>

<div class="proof">

*Proof.* The zeroth correlation is $`\int_{\mathbb{T}^2}\sin^2(2\pi y_1)\,\mathrm{d}\mu=1/2`$. The Fourier frequencies of $`\phi`$ are $`\pm e_1`$. The frequencies of $`\phi\circ T^k`$ are $`\pm(A^{\mathsf T})^k e_1`$. Hyperbolicity implies $`(A^{\mathsf T})^k e_1\ne\pm e_1`$ for every $`k\ge1`$. Orthogonality of distinct torus characters therefore makes every positive-lag correlation in <a href="#eq:green-kubo" data-reference-type="eqref" data-reference="eq:green-kubo">[eq:green-kubo]</a> vanish. ◻

</div>

## Imported homogenization theorem and specialization

For $`t\ge0`$, let $`X^\varepsilon_s(t)`$ be the piecewise-linear interpolation of $`x_n`$ at times $`t_n=n\varepsilon`$. The discrete deterministic-homogenization theorems apply to recurrences with increments of order $`\varepsilon`$ in the drift and $`\sqrt{\varepsilon}`$ in a centered chaotic observable . The following is their specialization to <a href="#eq:source-map" data-reference-type="eqref" data-reference="eq:source-map">[eq:source-map]</a>; the imported theorem, rather than MTT, supplies the analytic convergence.

<div id="thm:homogenization" class="theorem">

**Theorem 3** (Projected diffusion limit). *Fix $`S,T_0>0`$. For every fixed $`s\in[-S,S]`$,
``` math
X^\varepsilon_s\Longrightarrow X_s
\quad\text{in }C([0,T_0])
\quad\text{as }\varepsilon\downarrow0,
```
where $`X_s`$ is the unique solution of
``` math
\begin{equation}
\mathrm{d}X_s(t)
=
\bigl(\alpha(s-s_0)-\gamma X_s(t)\bigr)\mathrm{d}t
+\frac{1}{\sqrt2}\,\mathrm{d}W(t),
\qquad
X_s(0)=x_0.
\label{eq:ou-limit}
\end{equation}
```
The convergence is in law with respect to $`y_0\sim\mu`$.*

</div>

<div class="proof">

*Proof.* The hyperbolic toral automorphism and smooth centered observable satisfy the weak invariance principle. The slow drift is globally Lipschitz. The additive-noise case of the cited discrete homogenization theorem therefore gives the limiting affine Ornstein–Uhlenbeck equation. Lemma <a href="#lem:variance" data-reference-type="ref" data-reference="lem:variance">2</a> supplies the diffusion coefficient. ◻

</div>

#### What the limit says.

At finite $`\varepsilon`$, no Brownian path exists in the source model. Brownian motion describes the limiting law of many hidden deterministic histories when the fast and slow scales separate. The limit is an effective statistical description, not an ontological change in the source dynamics.

# The exact fixed-time threshold curve

Fix a readout time $`t>0`$ and define
``` math
q(s,t)=\mathbb{P}\bigl(X_s(t)>0\bigr).
```
This is an endpoint event. It is not the first-passage event $`\{\sup_{u\le t}X_s(u)\ge0\}`$.

The solution of <a href="#eq:ou-limit" data-reference-type="eqref" data-reference="eq:ou-limit">[eq:ou-limit]</a> is Gaussian. With $`\sigma^2=1/2`$, its mean and variance are
``` math
\begin{align}
m(s,t)
&=
x_0e^{-\gamma t}
+\frac{\alpha(s-s_0)}{\gamma}
\left(1-e^{-\gamma t}\right),
\label{eq:mean}\\
v(t)
&=
\frac{1}{4\gamma}
\left(1-e^{-2\gamma t}\right).
\label{eq:variance}
\end{align}
```
Let $`\Phi`$ and $`\varphi_{\mathrm{N}}`$ denote the standard normal distribution and density.

<div id="thm:threshold" class="theorem">

**Theorem 4** (Exact endpoint threshold law). *For every $`t>0`$,
``` math
\begin{equation}
q(s,t)
=
\Phi\!\left(\frac{m(s,t)}{\sqrt{v(t)}}\right).
\label{eq:q}
\end{equation}
```
It is strictly increasing in $`s`$, and its unique midpoint is
``` math
\begin{equation}
s_*(t)
=
s_0-\frac{\gamma x_0e^{-\gamma t}}
{\alpha(1-e^{-\gamma t})}.
\label{eq:midpoint}
\end{equation}
```
Its derivative is
``` math
\begin{equation}
\partial_s q(s,t)
=
\varphi_{\mathrm{N}}\!\left(\frac{m(s,t)}{\sqrt{v(t)}}\right)
\frac{\alpha(1-e^{-\gamma t})}
{\gamma\sqrt{v(t)}},
\label{eq:slope}
\end{equation}
```
and the maximum occurs at $`s=s_*(t)`$.*

*For $`0<p_1<p_2<1`$, let $`z_p=\Phi^{-1}(p)`$ and let $`s_p(t)`$ satisfy $`q(s_p(t),t)=p`$. Then the exact $`p_1`$-to-$`p_2`$ width is
``` math
\begin{equation}
s_{p_2}(t)-s_{p_1}(t)
=
\bigl(z_{p_2}-z_{p_1}\bigr)
\frac{\gamma\sqrt{v(t)}}
{\alpha(1-e^{-\gamma t})}.
\label{eq:quantile-width}
\end{equation}
```*

</div>

<div class="proof">

*Proof.* Equation <a href="#eq:q" data-reference-type="eqref" data-reference="eq:q">[eq:q]</a> follows from the Gaussian law with <a href="#eq:mean" data-reference-type="eqref" data-reference="eq:mean">[eq:mean]</a>–<a href="#eq:variance" data-reference-type="eqref" data-reference="eq:variance">[eq:variance]</a>. The coefficient of $`s`$ in $`m`$ is positive, giving strict monotonicity. Solving $`m=0`$ gives <a href="#eq:midpoint" data-reference-type="eqref" data-reference="eq:midpoint">[eq:midpoint]</a>. Differentiation gives <a href="#eq:slope" data-reference-type="eqref" data-reference="eq:slope">[eq:slope]</a>; the standard normal density has its unique maximum at zero. Finally, solving $`m(s_p,t)/\sqrt{v(t)}=z_p`$ and subtracting the two solutions gives <a href="#eq:quantile-width" data-reference-type="eqref" data-reference="eq:quantile-width">[eq:quantile-width]</a>. ◻

</div>

For example, the 10–90 width is obtained by taking $`p_1=0.1`$ and $`p_2=0.9`$. It is positive at every finite diffusion strength and tends to zero only in a zero-noise scaling. Thus “knee-like” means a rapid but continuous sigmoid, not a discontinuity or a phase transition.

# Return to the finite deterministic model

Define the finite-system endpoint curve at $`n_\varepsilon(t)=\lfloor t/\varepsilon\rfloor`$ by
``` math
q^\varepsilon(s,t)
=
\mu\left\{
y_0\in\mathbb{T}^2:
x_{n_\varepsilon(t)}(s,y_0)>0
\right\}.
```
Equation <a href="#eq:finite-solution" data-reference-type="eqref" data-reference="eq:finite-solution">[eq:finite-solution]</a> decomposes the endpoint into
``` math
x_{n_\varepsilon(t)}
=m_\varepsilon(s,t)+Z_\varepsilon(t),
```
where
``` math
\begin{align*}
m_\varepsilon(s,t)
&=
r_\varepsilon^{n_\varepsilon(t)}x_0
+\frac{\alpha(s-s_0)}{\gamma}
\left(1-r_\varepsilon^{n_\varepsilon(t)}\right),\\
Z_\varepsilon(t)
&=
\sqrt{\varepsilon}
\sum_{j=0}^{n_\varepsilon(t)-1}
r_\varepsilon^{\,n_\varepsilon(t)-1-j}\phi(T^j y_0).
\end{align*}
```
The random variable $`Z_\varepsilon(t)`$ is simply a deterministic function of the hidden initial condition.

<div id="prop:uniform" class="proposition">

**Proposition 5** (Uniform deterministic readout convergence). *For every $`t>0`$ and every compact protocol interval $`K\subset\mathbb{R}`$,
``` math
\sup_{s\in K}
\left|q^\varepsilon(s,t)-q(s,t)\right|
\longrightarrow0
\qquad
(\varepsilon\downarrow0).
```*

</div>

<div class="proof">

*Proof.* Theorem <a href="#thm:homogenization" data-reference-type="ref" data-reference="thm:homogenization">3</a> implies $`Z_\varepsilon(t)\Rightarrow N(0,v(t))`$. Because the limiting distribution function is continuous, weak convergence of the one-dimensional laws is uniform in the threshold argument. Also $`m_\varepsilon(s,t)\to m(s,t)`$ uniformly for $`s`$ in compact sets, since $`r_\varepsilon^{\lfloor t/\varepsilon\rfloor}\to e^{-\gamma t}`$. Writing each readout probability as the tail distribution of $`Z_\varepsilon(t)`$ at $`-m_\varepsilon(s,t)`$ proves the claim. ◻

</div>

<div id="cor:quantiles" class="corollary">

**Corollary 6** (Convergence of finite-system quantiles). *Fix $`t>0`$ and $`p\in(0,1)`$. Define
``` math
s^\varepsilon_p(t)
=
\inf\{s:q^\varepsilon(s,t)\ge p\}.
```
Then
``` math
s^\varepsilon_p(t)\longrightarrow s_p(t),
```
provided the infimum is taken in a compact interval containing the unique limiting quantile.*

</div>

<div class="proof">

*Proof.* For every $`\varepsilon`$, the deterministic mean in <a href="#eq:finite-solution" data-reference-type="eqref" data-reference="eq:finite-solution">[eq:finite-solution]</a> is strictly increasing in $`s`$, so $`q^\varepsilon(\cdot,t)`$ is nondecreasing. Proposition <a href="#prop:uniform" data-reference-type="ref" data-reference="prop:uniform">5</a> gives uniform convergence near the target, while Theorem <a href="#thm:threshold" data-reference-type="ref" data-reference="thm:threshold">4</a> makes the limiting curve continuous and strictly increasing. Standard monotone-quantile convergence then applies. ◻

</div>

This is the precise sense in which the finite deterministic system inherits the limiting knee: its endpoint probability curves and their quantile locations converge. No statement about first-passage times is needed.

# Comparison with stochastic and Markov descriptions

The limit <a href="#eq:ou-limit" data-reference-type="eqref" data-reference="eq:ou-limit">[eq:ou-limit]</a> is itself a parameter-dependent linear Markov diffusion. Consequently, the construction is not a no-go result against Markov models. A Markov model with the same $`s`$-dependent drift reproduces the limiting curve exactly.

What the deterministic model adds is a *source realization*: the Brownian forcing and its coefficient arise from a finite-dimensional invertible map plus an invariant ensemble. This distinction is useful:

- a fixed generator that contains no protocol coordinate cannot describe variation with that coordinate;

- a parameter-dependent Markov family can describe the variation directly;

- the source model explains one way such a family can emerge after hidden coordinates are discarded and scales are separated.

The parameter dependence is not created from nothing by projection. It is already present in the deterministic drift $`\alpha(s-s_0)`$. Projection and homogenization supply the effective diffusion law; the source protocol supplies the moving mean.

# Relation to MTT and physical measurement

The model has the abstract pattern
``` math
\begin{array}{c}
\text{invertible upper dynamics}\\
\downarrow\ \text{non-injective retained observable}\\
\text{effective stochastic law}
\end{array}
```
That pattern is compatible with projection-first formulations such as MTT, but compatibility is not source selection. To promote this example into an MTT result, one would still need:

1.  an explicit map from the selected MTT carrier and fixed-point dynamics to $`\mathbb{R}\times\mathbb{T}^2`$, or a replacement source system derived from that carrier;

2.  a theorem identifying the physical retained observable with $`P(x,y)=x`$;

3.  geometric sources for $`\gamma,\alpha,s_0`$ and the scale separation;

4.  a physical record-forming interaction and its operational outcome algebra; and

5.  a derivation of the relevant probabilities on that algebra.

None of those obligations is discharged by the present toy model. In particular:

- the invariant measure $`\mu`$ is supplied as ensemble data;

- the binary threshold is chosen, not derived;

- the Gaussian sigmoid is not the Born rule for arbitrary quantum contexts;

- endpoint thresholding is not wave-function collapse; and

- no empirical knee location is predicted.

The result is nevertheless useful as a consistency example. It proves that finite-dimensional invertible source dynamics is not, by itself, incompatible with a diffusive projected limit or a sharply varying lower-level outcome frequency.

# Status and conclusion

<div class="center">

| Object                    | Status                                      |
|:--------------------------|:--------------------------------------------|
| Finite source map         | Explicit smooth diffeomorphism              |
| Projection                | Explicit and non-injective                  |
| Probability source        | Declared invariant ensemble $`y_0\sim\mu`$  |
| Diffusion coefficient     | Exact, $`\sigma^2=1/2`$                     |
| Homogenization            | Imported rigorous theorem, specialized here |
| Threshold curve           | Exact fixed-time Gaussian law               |
| Finite-source convergence | Uniform on compact protocol intervals       |
| First-passage law         | Not claimed                                 |

| MTT source selection      | Open                                        |

</div>

The corrected construction reaches a modest but exact conclusion. A smooth invertible finite-dimensional map, observed through a non-injective coordinate and equipped with an invariant hidden-state ensemble, can converge to an affine diffusion. Its fixed-time binary readout has an exact finite-width threshold curve, and the corresponding finite deterministic curves converge uniformly on compact protocol intervals.

The result should be used as an existence proof and a diagnostic model. It does not show that all abrupt phenomena are caused by projection, and it does not replace a physical source theorem. Its value is that every ingredient responsible for the lower stochastic law is now visible: invertible source dynamics, hidden-state ensemble, observational projection, scale separation, and an explicitly protocol-dependent drift.
