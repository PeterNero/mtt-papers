# Version 9 Revision Note

Supersedes.
Version 8 of the grouped GPT corpus index.

Reason.
Topic grouping duplicated paper metadata, became stale as revisions were released, and obscured the distinction between historical text and current authority.

Resolution.
The grouped source is retained in the adjacent version-8 legacy file; this canonical notice directs readers and tools to the flat per-paper catalog and live status model.

Retained content.
The historical source remains available for provenance and for understanding the earlier custom-chat workflow.

Remaining boundary.
None. This artifact is retired navigation infrastructure and is not intended for Zenodo publication.

# Current Sources

- **Canonical papers, one directory per work:** [MTT papers repository](https://github.com/PeterNero/mtt-papers)

- **Reproducible result capsules:** [MTT results repository](https://github.com/PeterNero/mtt-results-repro)

- **Released records:** [MTT Zenodo community](https://zenodo.org/communities/mtt/)

The repository catalog supplies stable paper identifiers, current versions, source and PDF hashes, revision audits, result references, and Zenodo lineage. The Research Kernel projects that catalog together with the current A/B authority ledgers, result manifests, blocker states, repository heads, calculation jobs, and durable handoffs.

# Use Rule

Do not infer present research status from the legacy grouped index. Use the exact current paper object or A/B row from the Kernel, then follow its source and evidence references. Corpus search is for discovery; it does not promote an older claim over the current authority ledger.

# Publication Status

This notice and its historical source remain in the repository so that the migration is auditable. They are publication-exempt. There is no missing Zenodo deposit associated with this entry.
